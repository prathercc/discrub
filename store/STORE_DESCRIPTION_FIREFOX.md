Discrub is a Discord data management tool. It runs as a browser extension that activates on Discord, letting you export messages, search and filter conversations, purge messages and reactions, and work with offline data packages.

Features
- Export to HTML, CSV, JSON, or media-only, with 9 built-in presets and custom preset creation
- Discord data package import: drop your official Discord ZIP and browse it like a live account, with optional rehydration. Handles large multi-gigabyte packages and packages from any Discord locale
- Bulk export and bulk purge with filter support across multiple channels
- Search by content, author, date, mentions, message type, embeds, files, images, links, audio, video, stickers, and pinned status
- Refine loaded messages client-side without additional API calls
- Purge your own messages in servers and DMs, with attachments-only mode and archived thread handling
- Reaction management with per-user targeting and admin bulk removal
- System messages (pins, joins, boosts, thread-created) rendered inline; voice and stage channel chat browsable alongside text channels
- Click-to-jump on reply bars and thread starters, focused view mode for distraction-free reading
- Find threads even when their starter message has been deleted, via the Load Thread modal

Privacy
- Discord token stays in the browser
- No data sent to external servers
- All processing is local

Additional
- Dark and light mode (matches Discord theme)
- Forum channel support showing both active and archived posts
- Guided tour and contextual help icons
- Pause, resume, and cancel for long operations
- Discrub Classic (v1) built in
